## portfolio adapter for ioBroker

Regular stock price checks, fundamental analysis, price alerts, etc.

### Recommendation: create a separate user
It is recommended to create a separate user for ioBroker. As the usage of the api is officially not allowed, accounts may get blocked if the number of request is too high.

### Getting started

Create an account on https://www.finanzen.net/, everything else is in the adapter settings
